# Effects Roadmap Human Acceptance Script

Run this script in `npm run dev` after selecting a development match. Use the developer
controls to add the stated cards, set mana, summon targets, and advance turns. Record a
defect under PLAN.md's Known Issues section with the scenario ID if an observed result differs.

| ID   | Setup and action                                                                                                                                                   | Expected outcome                                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| H-01 | Open a normal match, mulligan, then play a Minion, targeted Spell, Weapon, and Hero card. Cancel one target selection before confirming it.                        | Only valid targets highlight; cancellation spends nothing; accepted plays update hand, mana, board, and event presentation once. |
| H-02 | Use draw, discard, shuffle, generated-card, overload, and mana-crystal cards. Fill a hand before drawing.                                                          | Costs, burns, hand/deck movement, overload lock, and mana display agree with the resolved state.                                 |
| H-03 | Apply a buff, debuff, Silence, stat swap, temporary keyword, and Divine Shield. End turns where required.                                                          | Effective stats and markers update immediately; temporary effects expire at their documented boundary.                           |
| H-04 | Deal damage through armor, restore health, destroy a minion, and create simultaneous deaths with a deathrattle.                                                    | Damage/armor/heal indicators attach to the affected character; deaths resolve once in stable order.                              |
| H-05 | Summon tokens/copies, return and transform minions, take control, resurrect, and fill a board before another summon.                                               | Entity movement is coherent, board capacity is respected, and no duplicate view remains.                                         |
| H-06 | Exercise Taunt, Stealth, Charge, Windfury, Freeze, immunity, Divine Shield, redirection, and weapon breakage.                                                      | Attack outlines and invalid-target feedback match domain legality; combat and durability are presented once.                     |
| H-07 | Trigger start/end-turn, summon, draw, damage, heal, deathrattle, granted, multiplied, and scheduled effects.                                                       | Each trigger fires in authored order once per qualifying fact; nested chains remain responsive.                                  |
| H-08 | Place aura, while-in-hand, spell-damage, healing, and hero-power scaling sources; remove/silence them.                                                             | Affected stats and costs recompute reversibly without drift; displayed values match resolved values.                             |
| H-09 | Play secrets, then invoke matching and non-matching events; include counter, redirect, prevention, and secret destruction.                                         | Secrets remain facedown until consumed/revealed, never leak early, and resolve in deterministic order.                           |
| H-10 | Equip/replace weapons, replace hero and hero power, apply multipliers, and let a turn timeout expire.                                                              | Hero, weapon, power, armor, durability, and match-end presentation remain coherent.                                              |
| H-11 | Use developer setup controls to create both players' hands, boards, mana, weapons, and a trigger chain; add and play cards normally to create secrets and history. | Controls use normal legality, input recovers after cancellation/rejection, and no AI decision is required.                       |

After all scenarios pass, mark the Human acceptance checkboxes in PLAN.md and attach any
remaining accepted defects to Known Issues.
